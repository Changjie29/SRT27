# SRT27 知识库（KB）

本目录存放 SRT27 故障诊断智能体的本地知识资料。后端启动时会扫描本目录下所有 `.md` 文件，按章节切块并建立关键词索引；用户提问时，RAG 模块检索最相关的片段注入 LLM system prompt。

## 目录约定

| 目录 | 用途 |
| --- | --- |
| `00_说明/` | 本说明与元信息 |
| `01_通用原理/` | 发动机、冷却、润滑、液压、电气、传动、制动、转向等通用机械原理 |
| `02_农机类型/` | 拖拉机、联合收割机、插秧机、植保机等类型级知识 |
| `03_新能源农机/` | 电动、混动、氢燃料农机 |
| `04_智能农机/` | 无人农机、自动驾驶、远程运维 |
| `05_故障代码/` | DTC / 故障码表与含义 |
| `06_品牌资料/` | 东方红、雷沃、中联、久保田、约翰迪尔等品牌通用资料 |
| `07_具体型号/` | 具体机型（如 MF-25D、DF-1204 等）专属维修手册内容 |
| `99_待整理/` | 临时放置、待归类的原始材料 |

## 文件格式约定

每个 `.md` 文件建议用二级标题（`##`）分隔章节，例如：

```markdown
# 发动机水温过高
## 现象
...
## 可能原因
1. ...
## 处理步骤
1. ...
## 注意事项
...
```

后端会按 `##` 切块，每块作为一个候选知识片段。

## 扩展

未来如需接入 PDF / Word / Excel / TXT，在 `server/knowledge/loader.ts` 中新增对应解析器即可，RAG 接口不变。
